# Fase 182 — Notifikasi untuk mode Gratis & perubahan masa aktif oleh admin
**Status:** Planned (urutan setelah Fase 181)
Mode "Gratis" (tanpa invoice) saat ini tidak memberi tahu pelanggan, begitu pula "Ubah Masa Aktif" (PATCH tanggal & perpanjang cepat). Rencana: notifikasi in-app (+email opsional) yang menyebut paket, tanggal lama, dan tanggal baru, supaya tidak ada perubahan masa aktif yang diam-diam. Keputusan terbuka: selalu diberi tahu atau hanya saat bertambah (saran: selalu).
